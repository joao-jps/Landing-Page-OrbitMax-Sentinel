### OrbitMax Sentinel

# Sistema web desenvolvido para conscientização, monitoramento e prevenção de queimadas, utilizando dados de eventos ambientais para auxiliar na visualização de ocorrências ativas e promover a preservação ambiental.

# O projeto foi desenvolvido como uma Landing Page interativa, com foco em experiência do usuário, responsividade e apresentação visual de informações relacionadas a desastres ambientais. A proposta é utilizar dados de eventos ambientais disponibilizados pela NASA EONET, uma plataforma que fornece informações sobre incêndios florestais, vulcões, tempestades e outros eventos naturais em escala global.

### 📌 Repositório: https://github.com/joao-jps/Landing-Page-OrbitMax-Sentinel.git
