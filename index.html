OrbitMax Sentinel

Monitoramento de queimadas via dados satelitais.

Explorar a Solução
01

O Problema

Queimadas

Focos no Pantanal detectados por satélite demoram horas para virar alertas úteis para brigadistas locais.

Deslizamentos

Áreas de risco geológico monitoradas por sensoriamento remoto não têm canal de comunicação com quem mora nelas.

+150 mil desabrigados por queimadas
R$ 86 bi em prejuízos estimados
3,8 mi hectáres queimados no Pantanal
02

Tecnologias

APIs abertas + Python + Arduino + Web = alertas acessíveis.

Dados Satelitais (NASA / INPE)

+

NASA FIRMS detecta focos de calor em tempo real. NASA EONET registra eventos climáticos extremos. INPE monitora o Brasil inteiro. via API pública e gratuita.

NASA FIRMS NASA EONET INPE

Processamento (Python)

+

Modelagem Matemática (Python)
As funções matemáticas processam os dados ambientais recebidos pelo sistema, realizando projeções de desmatamento, análise sazonal de queimadas e estimativas de impacto ambiental. Os algoritmos em Python executam os cálculos, geram gráficos e fornecem informações para apoiar a tomada de decisão.

Python 3 requests Matplotlib

Alerta Local/Físico (Arduino)

+

Protótipo com Arduino UNO simula estação de alerta local devido a fumaça gerada pela queimada, servidor gerado em python detecta e confirma a gravidade da situação: LED vermelho para risco crítico, buzzer sonoro e display LCD. Funciona sem internet estável.

Arduino Uno LED RGB Wokwi

Dashboard Web (HTML/CSS/JS)

+

Interface web exibe informações sobre o projeto, histórico de eventos e dados de satélite em tempo real, propõe interação com o usuário e recebe requisições do usuário por meio de cadastro via formulário. JavaScript puro, sem frameworks. Responsivo.

HTML5 CSS3 JavaScript
