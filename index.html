01

O Problema

Queimadas

Focos no Pantanal detectados por satélite demoram horas para virar alertas úteis para brigadistas locais.

Deslizamentos

Áreas de risco geológico monitoradas por sensoriamento remoto não têm canal de comunicação com quem mora nelas.

+150 mil desabrigados no RS em 2024
R$ 86 bi em prejuízos estimados
3,8 mi ha queimados no Pantanal
02

Tecnologias

APIs abertas + Python + Arduino + Web = alertas acessíveis.

Dados Satelitais (NASA / INPE)

+

NASA FIRMS detecta focos de calor em tempo real. NASA EONET registra eventos climáticos extremos. INPE monitora o Brasil inteiro. Tudo via API pública e gratuita.

NASA FIRMS NASA EONET INPE

Processamento (Python)

+

Scripts Python consomem as APIs, processam coordenadas, calculam o nível de risco e disparam notificações automáticas para gestores e comunidades.

Python 3 requests Matplotlib

Alerta Local/Físico (Arduino)

+

Protótipo com Arduino UNO simula estação de alerta local devido a fumaça gerada pela queimada, servidor gerado em python detecta e confirma a gravidade da situação: LED vermelho para risco crítico, buzzer sonoro e display LCD. Funciona sem internet estável.

Arduino Uno LED RGB Wokwi

Dashboard Web (HTML/CSS/JS)

+

Interface web exibe alertas ativos, histórico de eventos e dados de satélite em tempo real. JavaScript puro, sem frameworks. Responsivo.

HTML5 CSS3 JavaScript

No Dia a Dia
